# Governed design contract 2

## Scope

Fix the contract gaps exposed by Frostpeak QA run `04754d23-152a-465b-a20e-daef64727b38`, without another hosted request or editing saved QA records.

- New NVIDIA runs persist server-owned `design_contract_version: 2`. The planner and API payload cannot downgrade it. Existing runs without this marker keep their legacy contract.
- Every generated dialogue mapping declares its stage and quest/lifecycle/progress eligibility. Progress requires an active, incomplete attempt; completion requires a completed attempt. References must identify a declared typed quest.
- Every declared objective/failure/restart event has a descriptive `event_actions` entry. Missing/extra entries and identifier-only descriptions are rejected. Derived integration checks use these descriptions. The underlying independent-boolean quest state contract remains version `1`.
- New critic findings use a canonical section and an exact artifact JSON pointer/value plus proposed replacement. Stale values, wrong sections, no-op replacements and quotes absent from frozen evidence block review. Original findings are retained, not automatically dismissed.
- Invalid critic references cannot be removed through human finding resolutions. Valid independently anchored findings retain the existing explicit human-review route. Malformed contract-2 critiques fail closed without a repair request that could invent references.
- Generation, scoped revision, current quality assessment and persisted approval use the same versioned requirements. Contract-2 revisions use the existing full section contract rather than the legacy compact dialogue patch.

No dependencies, environment/model settings, migrations, runtime approvals, frontend redesign, commits or pushes were introduced.
